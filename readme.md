
# Graph Coloring and Exam Timetable Scheduling

## Project Overview
This is an ADSAA mini project that generates a college examination timetable using Graph Coloring and Backtracking.

## Objectives
- Avoid examination clashes for students.
- Assign time slots to different subjects.
- Demonstrate Graph Coloring and Backtracking algorithms.

## Technologies Used
- Programming Language: Python
- Algorithm: Graph Coloring
- Technique: Backtracking

## How It Works
1. Enter subjects and student registrations.
2. Build a graph connecting subjects with common students.
3. Assign examination slots using graph coloring.
4. Use backtracking to resolve conflicts.
5. Display the generated timetable.

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

   python main.py

## Application
College examination timetable scheduling.
